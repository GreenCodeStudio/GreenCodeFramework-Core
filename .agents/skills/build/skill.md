---

to build project run in pwsh

```pwsh
. ./script.ps1
build-project
```

To start dev server run in pwsh

```pwsh
. ./script.ps1
start-devServer
```

You can do it in parralel by:

```pwsh
. ./script.ps1
start-project
```
